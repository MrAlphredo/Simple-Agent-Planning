A simple starting point to start an agentic planning session.

For simpler project, calling a planning round to flesh out the project is enough to make the rest of your journey smooth, agentic or not.

For larger projects, invoke planning round for every layer, from top down. Start with an overall goal and scope, then split it into submilestones or components. 
Slowly flesh out each bit as you progress, recalling the planning round whenever needed.

This will work for almost any type of project, leaving you a very organized workspace, easy for other agents to pick up.
